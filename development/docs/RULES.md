# 当前规则与边界：2026-10-22 长任务扩展

没有风险审批或独立任务审查模型。用户本轮明确要求并授权了 **90% 自动压缩、文件计划与子代理、分段写入、容量断点续跑**，因此现在有这些可见、可配置的运行机制。不能继续沿用上轮“到限一定停止、无任何自动续跑”的结论。

## 实际新增机制

| 机制 | 当前实现和边界 |
| --- | --- |
| 压缩触发 | 默认 auto_compact=true，threshold=.9，target=.6；按（保守输入估算＋输出预留）/配置容量触发，不是精确 tokenizer 的 90%，累计 usage 不参与 |
| 压缩内容 | 归档完整闭合的旧 assistant/tool 事务，用户消息与 system 原文保留；当前计划、模型工作断点、最近文件版本和子结果生成工作索引。原始消息不删，旧分支不改 |
| 不是语义无损摘要 | 不调用额外总结模型；索引只保存事实摘录与坐标。早期讨论细节/决策可能不在当前索引，模型需用 history_read 取回；不能保证不遗漏语义 |
| 容量无法腾出 | 用户原文或计划/必要索引本身过长时，记录 context_limit 停止，不悄悄删用户要求 |
| 模型指导 | 多文件任务建议先 task_plan 列职责及公共接口，再 agent_task；工具选择和执行顺序仍由模型决定，无关键词分类器或额外规划模型 |
| 子代理 | 单层、串行，使用同一个本地模型和独立消息分支；只传用户原要求、完整项目文件职责表、接口和分配任务，不复制主代理源码历史。默认文件/文档/历史/断点工具；模型可通过计划的 tools 字段显式指定浏览器/MCP等其他已注册工具。文件写工具只改分配路径；不是 OS 沙箱 |
| 子代理结果 | 父代理只收短报告、状态、文件元信息和分支坐标，完整子记录独立保存；正常结束不代表独立通过，父代理负责整合 |
| 分段编辑 | append 核对 UTF-8 字节位置，可选 SHA256；replace 原文必须唯一匹配。每次完整调用先快照；实现仍保存/写入完整文件版本，不是流式文件上传 |
| 输出到限续跑 | auto_continue=true 时，保存截断原始响应，半截工具参数不执行，下次请求明确说明从最后完整动作继续。模型保持加载，不自动卸载/重载 |
| 不自动处理的失败 | 普通工具异常、服务错误、验收不通过不触发运行时补救；重新调用工具由模型决定。服务崩溃后的自动重载未实现 |
| 续跑终止 | 沿用用户停止及整轮超时，不额外设置搜索/任务次数配额。模型若持续不能缩短输出，仍可能消耗预算直到超时，不保证靠续跑解决 |

## 其他保留约束

消息角色、工具参数 Schema、完整事务和分支内工具 ID 唯一；归档之后仍核对全量原消息。模型响应模板只收到开头的一条合并 system，原始记录保持不变。默认上下文32768、输出8192；本机私有设置需匹配实际加载容量。默认模型请求180秒、整轮600秒，可在界面调整；参数实验的配置单独保存在现场。

文件工具、浏览器上传和本地 HTML 限于所选工作区，`.clearact` 记录受保护；文件写前快照，恢复核对当前哈希。对话分支共享文件，快照不能撤销网页提交和远端 MCP 副作用。

上传默认每文件64MB（CLEARACT_UPLOAD_MAX_MB可调），原始 blob 与可编辑副本分开；重新挂载时核对副本哈希。文本读取最多12000字/次，目录最多200项，浏览器元素/MCP工具最多100项，可继续分页；没有搜索次数配额。

工作区写锁保证一次运行；运行中不允许改设置、切换工作区、上传、分叉、恢复或重配 MCP。浏览器手动操作可用，与模型动作串行。浏览器每动作45秒，首页面默认定位15秒；MCP 默认连接15秒/调用60秒，可按服务配置，连接失败需显式重连。

本地网关监听 loopback，校验 Host/Origin/CSRF/CSP；密钥、MCP env/headers 不回显，原始参数与结果可能含用户隐私，记录本地保存不自动上传。MCP命令、参数和URL可见，避免把令牌直接写在其中。

没有独立审查模型、风险等级、关键词意图分类、资料优先级、搜索配额、重复操作检测或自动验收催促。追加的字节/哈希核对属于文件版本一致性，不是重复行为检测。模型选择检查或修正与运行框架主动追加验收补救提示分开。

## 能力范围与审计

浏览器为独立 Edge/Chromium 上下文，不继承个人登录态，截图用于用户预览和交付，未接多模态模型输入。MCP支持stdio/Streamable HTTP/SSE，未接交互OAuth，外部服务认证/审批由其自身决定。PDF/DOCX/XLSX可读取；扫描PDF未接OCR，旧.doc/.xls未解析，没有独立命令执行或专用Office写入工具。

实际系统提示以 runtime/runner.py 的 SYSTEM 为准，工具说明以注册 Schema 为准。审计覆盖 context、runtime、core、tools、application、storage、gateway、web；与当前源码哈希绑定在本轮 records/evals/long-work-20261022-193610/rules-audit.json。旧批次结论只适用于当时源码。
